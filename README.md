## 🤖 Offline SQL Query Generator (NL2SQL)

> **Standalone Enterprise RAG System for Natural Language to PostgreSQL Generation**

<img align="right" width="280" src="https://img.shields.io/badge/Enterprise-NL2SQL-blue?style=for-the-badge"/>

### 📌 Overview

Architected a standalone **offline RAG pipeline** combining vector embeddings, semantic retrieval over **pgvector**, and schema-aware context injection to ground **Qwen LLM** outputs directly in the database schema—with zero external API dependencies.

Built a **self-correcting SQL generation loop** that validates generated PostgreSQL queries, catches execution errors, and iteratively repairs failed statements.

### ⚙️ Tech Stack

<p>
<img src="https://skillicons.dev/icons?i=python,fastapi,postgres"/>
<img src="https://img.shields.io/badge/pgvector-4B8BBE?style=for-the-badge"/>
<img src="https://img.shields.io/badge/RAG-1E90FF?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Qwen%20LLM-615CED?style=for-the-badge"/>
</p>

### ⭐ Key Features

- 🧠 Natural Language → PostgreSQL Conversion
- 🔍 Vector Embeddings & Semantic Retrieval over pgvector
- 📚 Schema-Aware Context Injection
- 🤖 Local Qwen LLM Inference (Zero External APIs)
- ⚡ FastAPI Backend Service
- 🛡 Automated SQL Validation Workflow
- 🔄 Self-Correcting Error Recovery Loop
- 🗄 PostgreSQL Integration

### 🏗️ Workflow

```text
User Question
      │
      ▼
Vector Embeddings & Semantic Retrieval (pgvector)
      │
      ▼
Schema-Aware Context Injection
      │
      ▼
Local Qwen LLM
      │
      ▼
SQL Validation & Error-Recovery Loop
      │
      ▼
PostgreSQL Execution
      │
      ▼
Results
```

### 🎯 Business Impact

✔ Reduces manual SQL writing for analytics teams

✔ Enables natural-language querying over enterprise databases

✔ Improves SQL accuracy and reliability through RAG & self-healing validation

✔ Runs 100% offline for private enterprise environments
